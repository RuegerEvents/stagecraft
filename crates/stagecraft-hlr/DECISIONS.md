# stagecraft-hlr decisions

Decisions taken while building the crate unattended (2026-11-18). Newest last.

| Topic | Decision | Why |
|---|---|---|
| Crate shape | Standalone crate with its own `[workspace]` table, own input types (`Mesh`, `Line3`, `Scene`, `View`), no StageCraft deps. glam 0.34 (`DVec3`, f64), earcutr 0.5, optional rayon. | Built in parallel with other agents; integration maps `geom::Mesh` + world transform to `Mesh` in one small function. |
| Section convention | `SectionPlane` normal points to the **removed** side, like `stagecraft-geom::section::Plane`. A vertex exactly on the plane counts as kept. | One convention across the 3D clip and vector sections. |
| View space | Right-handed (right, up, towards eye). Depth test: an occluder hides a point when its plane lies more than the depth tolerance closer to the eye. Output y is up; the SVG writer flips. | Matches PDF/sheet maths (y up) and keeps cross products outward. |
| Presets | front = from the audience looking +y, side = from stage right, iso = from front right above. Plan view coordinates equal world x/y. | Same as the 3D view's standard views (docs/spec/decisions.md 2026-11-18). |
| Welding | Grid of 2·tol cells, 8 lookups per point (own cell plus the near neighbour per axis). Default 0.01 mm. | Exact within tol, no misses at cell borders; GDTF/3DS meshes are usually flat-shaded with split vertices. |
| Slivers | A triangle thinner than 0.1·tol (height over its longest edge) is dropped; T-junction repair then closes the gap. | Sliver normals are noise and would draw false creases. |
| T-junctions | Boundary vertices lying inside another boundary edge split that triangle (fan). Only boundary edges are examined. | Flat faces from CAD exports otherwise show false boundary lines. Cheap: only open edges. |
| Orientation | BFS over manifold edges per component. Closed shells: outward by signed volume, flipped when nested in an odd number of other closed shells of the same mesh (ray parity, bbox prefilter). Open sheets: majority winding. | Silhouettes and creases are invariant under a global flip, but back-face culling is not; hollow parts need inward cavity walls. |
| Back-face culling | Back faces of closed shells are not used as occluders (about half the triangles). Open meshes use all faces. | Safe: along any ray into a closed solid the first surface is front-facing. |
| Crease default | 50°, not 30°. | Truss diagonals and GDTF tubes are often 8-sided (45° facets); at 30° every facet edge showed. Box edges (90°) and most real creases stay. |
| Silhouette rule | Edge between a face with `n·eye > 1e-9` and one without. Edge-on faces count as back-facing. | An edge-on strip yields exactly one silhouette instead of two coincident ones. |
| Occlusion test | Per (edge, triangle): one interval from three half-planes enlarged by a tiny xy epsilon (inclusive) plus the depth half-line. Edge-on triangles (`|n.z| < 1e-6·|n|`) are skipped. | Exact and linear; inclusive edges hide back edges lying under a front outline and lines along a face diagonal (iso cube). Skipping edge-on triangles bounds the depth slope. |
| Tolerances | xy eps = 1e-10·extent + 1e-7 mm; depth eps = max(1e-7·extent, 0.001 mm). | Scale-aware; stage scenes are up to ~50 m. |
| Spatial index | Uniform grid, about one cell per occluder, ≤ 4096 per side, CSR storage; triangles and query segments rasterised per row strip (not bbox) so long diagonal members do not fill whole rectangles; per-query stamp array for dedup; early out when one triangle hides the whole edge. | Simple, predictable, wasm-friendly; 309 k triangles in 0.1–0.45 s single-threaded. A BVH was not needed. |
| Overlap removal | After HLR: hidden under visible/cut, visible under cut, and same-class duplicates within one object are removed (collinear within the weld tolerance, grid lookup, tolerance band on insert). Different objects' visible lines are not merged. | Front views of boxes otherwise get dashed lines exactly under every outline. Keeping both objects' visible lines leaves per-object weights to the caller. |
| Cut regions | Loops chained by exact keys (vertex or edge id), nesting by even-odd containment in plane coordinates, caps triangulated with earcutr and used as two-sided occluders. Regions are skipped when the plane is edge-on to the view. | No tolerance chaining needed on welded meshes; caps stop "seeing into" cut solids. |
| Cut lines | Cut loops and open chains go through HLR like edges; their hidden parts become `Hidden`. | Correct for oblique planes; for presets they are always visible. |
| Hidden centre lines | Hidden parts of `Line3` with class `Centre` are dropped (not dashed). | A dashed centre line reads like a hidden edge. Set `occluded: false` to draw centre lines over everything. |
| Parallelism | Feature `parallel` (off by default): rayon over meshes and over HLR queries. Overlap removal and chaining stay serial. Output is identical. | wasm builds without features; the app enables it natively. |
| Output | Polylines chained per (object, class); collinear interior points removed with the weld tolerance. | Small PDFs, clean dashes across segment joins. |
| Intersection lines | Added (`Options::intersections`, on by default): strict triangle–triangle crossings between different meshes or different components of one mesh. Component pairs by sweep-and-prune over boxes in world axes; per pair only triangles inside the overlap box, brute force up to 4096 pairs, else a hash grid. They rank below every edge in overlap removal ("weak"). | Truss diagonals into chords and clamps around tubes looked wrong without the meeting curve. A first version with a global 3D grid in view space took 16 s for the iso benchmark (rotated long members fill huge boxes); the component sweep takes ~0.3 s. |
| Weak hidden lines | Hidden intersection pieces also yield to ordinary hidden lines of any object. | Otherwise every penetration doubles the dashed lines along the hidden edges it lies on. |
| Not done | Per-mesh crease angles; cut-region occlusion for oblique planes; self-intersections inside one component. | See README "Limits". |
